### 👨‍💻 About Me

I am a **Computer Science and Engineering (CSE)** student at **BRAC University**, Dhaka, Bangladesh. My work bridges **Computer Vision research** and **scalable software engineering** — designing lightweight deep neural architectures that deliver real-time inference on edge hardware, as well as building robust full-stack web platforms.

- 🔭 **Current Research & Focus**: Developing **[AGL-YOLO](https://github.com/Joy-Khan007/AGL-YOLO-Fabric-Detection)** — an ultra-lightweight (1.2M parameter) Attention-Guided YOLO model for microscopic fabric spot defect detection running at **81.4 FPS**.
- 💡 **Interests**: Deep Learning, Computer Vision, Edge AI, Object Detection, Full-Stack Architecture, and Distributed Systems.
- 🎓 **Education**: B.Sc. in Computer Science & Engineering, BRAC University.
- 🤝 **Collaboration**: Open to collaborating on Computer Vision, AI-driven automation, and modern web application development.
- 💬 **Ask me about**: YOLO architectures, attention mechanisms (CA, SimAM), PyTorch, Spring Boot, and Python.
